# Конфигуратор сервопривода Feetech STS3215

Desktop-приложение на Python для конфигурации, калибровки и диагностики сервопривода
**Feetech STS3215**, подключённого через контроллер **Waveshare Servo Driver with ESP32**
(SKU 21593) по USB Type-C / Serial.

> Статус: этап 0 — каркас проекта. Разделы ниже заполняются по мере реализации.
